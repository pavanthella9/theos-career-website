# Theos Career Consultants Website

Production-ready first build for a training, recruitment and placement-assistance business serving India, Singapore and Malaysia.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project (do not upload `node_modules`).
3. Sign in to Vercel with GitHub.
4. Select **Add New → Project** and import the repository.
5. Keep the detected Next.js settings and click **Deploy**.
6. In Vercel, open **Settings → Domains** to add your new domain.
